# PC 설정에서 설치 프로그램 업데이트

Status: ready-for-human

## 확인한 상태
- PC 설정에는 GitHub Releases 확인 → 사용자 확인 → Setup 다운로드 → SHA-256 검증 → 설치 프로그램 실행 → 앱 종료 흐름이 이미 구현되어 있다.
- 현재 공개 릴리스는 `v1.0.0-rc.1` 한 개이며 이전 설치본이 첨부되어 있다. 로컬 새 빌드와 공개 버전이 같아 새 기능을 업데이트로 전달하지 못한다.

## 작업
- 새 Windows 배포 후보 `1.0.0-rc.2+54` 준비.
- pubspec 버전에서 설치본 이름과 Windows 숫자 버전을 자동으로 생성해 릴리스 태그와 파일명 불일치를 방지.
- 빌드 번호를 포함하는 태그에도 기본 버전명 설치본을 인식.
- 검증 정보가 없는 파일은 UI에서 실행할 수 없도록 표시하고 일반 오류도 사용자에게 안내.
- 설치 파일 URL/파일명을 확인하고, 실패 시 앱을 종료하거나 설치 파일을 실행하지 않는 테스트 강화.
- Windows 설치본 생성 및 배포할 릴리스 노트 준비.
- 공개 릴리스 게시가 완료되어야 설치된 앱의 버튼으로 실제 다운로드 가능. 기존 공개 릴리스는 변경하지 않는다.

## 구현 상태
버전·설치 파일 처리와 오류 안내 보강 및 Windows 설치본 생성 완료. 사용자가 소스 푸시와 공개 배포를 승인했으며, 앞으로 모든 Windows 업데이트 릴리스에 Setup/Update EXE를 함께 게시하도록 요청했다. `scripts/publish_windows_release.ps1`과 AGENTS.md에 해당 절차를 반영했다. 상세 결과는 `IMPLEMENTATION.md` 참고.
