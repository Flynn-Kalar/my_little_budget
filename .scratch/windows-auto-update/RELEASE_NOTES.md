# My Little Budget 1.0.0-rc.2 (build 54)

- 최근 거래에서 계좌·카테고리·태그를 불러오는 입력 추천
- 선택한 거래의 카테고리·태그 일괄 수정
- 그룹별 하루 사용 가능 예산
- 거래 CSV 가져오기·내보내기 및 오류·중복 미리보기
- 자동 로컬 복구 지점 보관과 복원 미리보기
- 좁은 PC 창의 접이식 핵심 요약과 상단 스크롤
- 월간 통계에서 선택한 카테고리·태그 내역 정리 및 같은 월 예산 조정으로 이동
- 월말 예상의 미래 거래 중복 계산 및 이체 차감 수정
- PC 설정의 최신 버전 확인에서 검증된 설치 파일을 다운로드해 업데이트 실행
- 설치 파일 준비 상태 안내와 업데이트 오류 처리 보강

기존 가계부 데이터는 유지됩니다. 삭제 실행 취소 기능은 포함하지 않습니다.

Windows 설치 파일: `MyLittleBudget-Setup-1.0.0-rc.2.exe`
Windows 업데이트 파일: `MyLittleBudget-Update-1.0.0-rc.2.exe`
두 파일 검증값: `SHA256SUMS.txt`
릴리스 태그: `v1.0.0-rc.2`
