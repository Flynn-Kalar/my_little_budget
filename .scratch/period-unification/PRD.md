# 월별 집계 기간 통일

## 요청
- 홈, 예산, 통계, 투자 등 월별 금융 화면의 조회 기간과 월 이름을 설정된 집계 기간으로 통일한다.
- 반복거래의 지정된 발생일은 유지한다. 집계 시작일에 현재 집계 종료일까지 예정 거래를 생성한다.

## 구현
- 날짜가 속한 집계 기간과 표시 연도별 기간 계산을 공통 StatementPeriod에 추가한다.
- 현재 진행 중인 집계 기간을 초기 선택 및 오늘 이동에 사용한다.
- 모바일과 PC 각각 월 제목에 시작월/종료월 설정을 적용한다. 월 선택은 표시월에서 저장용 월로 역변환한다.
- 홈 합계, 예산 사용액/이월/경고/계좌 연동/하루 사용 가능 금액, 통계 카테고리/태그/추세/연간 집계, 투자 월간/연간 조회 및 손익에 같은 기간을 적용한다.
- 카드 잔액의 예정 거래 반영 기한도 현재 집계 종료일로 통일한다.
- 예산과 예상 소득의 저장용 월 키는 유지한다. 월 표시 방식 변경으로 데이터가 다른 월로 이동하지 않는다.
- 반복거래는 앱 시작/복귀/집계 기간 전환/시작일 설정 변경 시 동기화 이후 생성한다. 날짜나 환경설정 알림만으로 동기화 전에 자동 생성하지 않는다.
- 이미 생성된 거래는 삭제하거나 날짜를 변경하지 않는다. 기존 마지막 생성일 및 중복 방지 로직을 유지한다.
- 달력/일정 화면의 실제 달력 월은 그대로 사용한다.

## 검증
- 집계 경계 전후의 홈·예산·내역·통계 합계 일치 및 태그 상세 내역 검사.
- 월 표시 설정 변경 시 예산 보존 및 그래프 라벨 변경 검사.
- 반복거래 지정일 유지, 달력 1일에 다음 기간을 생성하지 않음, 집계 시작일의 다음 기간 생성 및 멱등성 검사.
- 연도 경계를 넘는 연간 통계/투자 조회, 공휴일 보정 경계 및 하루 예산 검사.
- 전체 591개 테스트 통과. 이후 표시월이 중복되는 모바일 그래프 선택 회귀 테스트를 추가했고, 관련 17개 테스트 통과.
- lib/test 정적 분석 오류·경고 없음, git diff --check 통과.
- 공휴일 보정으로 표시월이 겹쳐도 그래프 선택에는 고유 집계 기간 키를 사용한다.
