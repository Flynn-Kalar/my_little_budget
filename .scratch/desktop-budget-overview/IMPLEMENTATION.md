# 구현 및 확인

2026-10-19 PC 예산 화면 상단 배치를 반영했다. 빌드·설치·GitHub 배포는 수행하지 않았다.

- 예상 소득 카드는 기존처럼 상단 전체 폭에 둔다.
- 요약/하루 예산을 하나의 PC 개요 영역으로 묶었다. 가용 폭 820 이상에서 왼쪽 3개 요약 카드와 오른쪽 하루 예산 카드의 위아래 높이를 맞춘다.
- 좁은 PC 영역은 같은 두 영역을 세로로 배치한다. shell/플랫폼 판정과 공통 breakpoint는 변경하지 않았다.
- PC에만 기준 일수를 제목 아래 한 번 표시하는 옵션을 사용한다. 모바일의 기존 그룹별 일수 표시는 그대로다.
- 지난 달이나 그룹 없음 상태는 빈 오른쪽 영역 없이 요약과 기존 그룹/빈 상태를 표시한다.
- 예산 합계·사용액·잔액·하루 예산 계산식 및 기존 그룹 카드의 수정/삭제 동작을 유지했다.

검증:

- 개요 화면/이동/통계 연계 테스트 18개 통과. 넓은/좁은 화면 배치, 좌우 높이 일치, 기준 일수 표시 횟수, 과거/빈 예산, 모바일 기본 표시를 확인했다.
- 예시 데이터로 가용 폭 1100/620 화면을 렌더링해 카드 배치와 줄바꿈을 확인했다. 미리보기는 무시되는 `build/budget-overview-1100.png`, `build/budget-overview-620.png`에 있다.
