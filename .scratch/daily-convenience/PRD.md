# 일상 입력 및 데이터 관리 편의성

Status: ready-for-human

## 범위
- 최근 입력 추천: 신규 거래에서 메모와 같은 유형의 최근 거래를 추천하고 사용자가 선택하면 계좌·카테고리·태그를 채운다. 금액과 날짜는 유지한다. 보관된 계좌/카테고리는 제외한다.
- 일괄 수정: 현재 조회 결과 중 거래를 선택해 카테고리와 태그를 변경한다. 유형 불일치는 거부하고 전체를 원자적으로 저장한다.
- 생활 단위 예산: 예산 그룹별 남은 금액을 오늘 포함 남은 날짜로 나누어 안내한다. 예정 거래는 기존 사용액 기준으로 이미 차감한다. 지난달에는 하루 금액을 표시하지 않는다.
- CSV: UTF-8 거래 내보내기, 열 연결, 검증 및 중복 미리보기 후 원자적 가져오기. 계좌/카테고리는 기존 활성 항목 이름으로 연결한다. JSON 백업과 별도 기능이다.
- 자동 로컬 백업: 앱 시작과 사용 중 데이터 변경 후 하루 한 번, 최근 7개 보관. 설정에서 즉시 생성·내보내기·복원 제공. 기존 JSON 및 원격 복원에도 날짜와 건수 미리보기 및 복원 직전 안전 백업을 제공한다.

## 제외
- 삭제 실행 취소
- 제안 후반의 화면 재배치, 통계 연결, 월말 결산
- 은행 연결 및 금융기관별 전용 파일 포맷

## 검증
정적 분석, 추천·일괄 수정·CSV·예산 계산·백업 보존/실패 관련 테스트, 관련 기존 UI 테스트.

범위 내 5개 기능 구현 및 검증 완료. 상세 동작과 검증은 `IMPLEMENTATION.md` 참고.
