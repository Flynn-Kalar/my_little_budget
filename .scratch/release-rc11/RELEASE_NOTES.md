# 나만의 작은 가계부 1.0.0-rc.11 (60)

## 변경 사항

- 메모 유형 선택을 없애고 금액 목표를 본문 삽입으로 통합했습니다. 기존 목표 메모와 임시 작성 내용의 목표는 편집할 때 본문으로 가져오며, 저장 전까지 원본을 유지합니다.
- 고정 메모끼리, 일반 메모끼리 각각 순서를 바꿀 수 있습니다. 저장한 순서는 메모 수정 후에도 유지하며 백업과 기기 간 동기화에 포함됩니다.
- 반복 거래는 별도 창 없이 현재 목록에서 순서를 편집합니다. 모바일 자산·태그·카테고리도 위·아래 이동 후 취소하거나 순서 저장하는 방식으로 통일했습니다.
- 일정 시간대를 지역명 / UTC ±N 형식으로 표시하고, 입력 검색과 드롭다운 선택을 제공합니다. 한국어·영문 이름·주요 지역의 현지 표기와 UTC 시간 차이로 검색할 수 있습니다.
- 일정 날짜의 서머타임과 30분·45분 시차를 표시합니다. 새 일정은 기기에서 조회한 시간대를 기본으로 사용하고 기존 일정의 시간대는 유지합니다.

## 검증 및 파일

- 전체 테스트 570개 통과, 정적 분석 문제 없음.
- Windows Setup.exe와 Update.exe는 같은 전체 설치 패키지이며 기존 설치와 데이터를 유지하며 업그레이드합니다.
- Android AAB는 Google Play 업로드용 서명 번들이며 versionCode는 60입니다. GitHub 게시와 Google Play 배포는 별개입니다.
- SHA256SUMS.txt로 Windows 파일 두 개와 Android AAB를 검증할 수 있습니다.
- 로컬 DB는 메모 순서 저장을 위해 v26으로 자동 갱신됩니다. 기존 메모와 이전 백업은 유지합니다. 이번 변경을 위한 서버 SQL 추가 작업은 없습니다.
