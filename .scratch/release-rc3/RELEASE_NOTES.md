# My Little Budget 1.0.0-rc.3 (build 55)

- PC·모바일에서 내역을 길게 눌러 다중선택 시작: 평소에는 체크박스를 숨깁니다.
- PC 선택 모드에서 Shift 범위 선택을 지원합니다.
- 별도 선택 창 없이 기존 내역 목록에서 카테고리·태그를 일괄 수정합니다.
- 선택 건수와 수입·지출 합계, 조회 결과 전체 선택, 선택 해제 및 선택 모드 종료를 제공합니다.
- 태그를 분류별 사용 빈도와 전체 사용 빈도에 따라 정렬하며 모든 태그를 선택할 수 있습니다.
- 태그 선택 중 순서와 버튼 위치를 유지합니다.
- PC 빠른 입력에서 태그 입력 후 Enter를 누르면 쉼표를 붙이고 태그 칸에 머뭅니다. 쉼표 뒤 빈 상태에서 Enter를 누르면 내용으로 이동합니다.
- 태그 자동완성 시 앞서 입력한 태그를 보존합니다.
- 노트 본문·모바일 빈 영역을 눌러 편집할 수 있도록 개선하고 체크리스트 변경 감지를 보완했습니다.

Android: 서명된 AAB, 버전 코드 55 (`MyLittleBudget-Android-1.0.0-rc.3.aab`).
Windows: 신규 설치용 Setup EXE와 앱 내 업데이트용 Update EXE를 함께 제공합니다.
`SHA256SUMS.txt`에는 AAB와 두 EXE의 검증값이 포함됩니다.
기존 데이터는 동일한 앱 식별자로 업그레이드해 유지합니다.
