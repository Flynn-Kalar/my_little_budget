# 나만의 작은 가계부 1.0.0-rc.12 (61)

## 변경 사항

- PC와 모바일 메모의 체크리스트 클릭·터치 영역을 최소 48픽셀로 확대했습니다. 체크박스 주변을 눌러도 편집 화면으로 넘어가지 않고 체크 상태를 변경합니다.
- 작은 글씨와 들여쓰기 항목에도 넓은 체크 영역을 적용하고 체크 표시의 가독성을 개선했습니다.
- Android 알림과 전체 화면 알람에 체크리스트·일정으로 이동하는 동작을 보완했습니다. 이동할 때 알람을 정리하고 항목의 완료 상태는 유지합니다.
- 메모 금액 목표 본문 통합, 고정·일반 메모의 순서 편집, 일정 시간대 검색과 기기 기본 시간대 개선을 포함합니다.
- Google Play 내부 테스트 업로드용 API 스크립트를 추가했습니다. 인증 파일은 저장소 밖에 보관합니다.

## 파일

- Android versionCode는 61입니다. 내부 테스트 배포 대상입니다.
- Windows Setup.exe와 Update.exe는 같은 전체 설치 패키지로 기존 설치와 데이터를 유지합니다.
- SHA256SUMS.txt로 두 EXE와 AAB를 검증할 수 있습니다.

검증: 전체 Flutter 테스트 574개 통과, 정적 분석 문제 없음.
