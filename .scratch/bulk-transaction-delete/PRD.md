# 선택 모드의 거래 일괄 삭제

- PC/모바일 공통 선택 작업바에 삭제 버튼을 추가한다.
- 선택 없음/처리 중에는 삭제할 수 없다.
- 삭제 전 선택 건수와 수입·지출 합계를 표시한다. 이체는 별도 합계로 구분한다.
- 취소하면 선택과 데이터를 유지한다. 확인한 거래만 원자적으로 삭제하고 태그 연결과 동기화 삭제 기록은 기존 단건 삭제와 동일하게 처리한다.
- 삭제 후 선택 모드를 종료하고 내역/잔액/예산/통계를 갱신한다.
- 오류가 발생하면 일부만 삭제하지 않고, 선택을 유지한 채 작업바에 오류를 표시한다.
- 코드 개선 요청 범위이며 빌드·설치·배포는 포함하지 않는다.
