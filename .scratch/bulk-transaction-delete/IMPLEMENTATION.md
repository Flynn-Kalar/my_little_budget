# 선택한 거래 삭제 구현

2026-10-19 코드 반영. 이번 요청에서는 빌드/설치/GitHub 배포를 수행하지 않았다.

- PC/모바일 공통 선택 작업바에 삭제 버튼을 추가했다. 선택 없음/처리 중에는 비활성화한다.
- 삭제 확인창에 건수, 수입·지출 합계와 이체 별도 합계를 표시한다. 확인 대상 ID를 복사하고 확인/처리 중 선택 변경을 막는다.
- 취소 시 선택과 데이터를 유지하고, 성공 시 선택 모드를 종료하고 기존 갱신 함수를 통해 내역·잔액·예산·통계를 갱신한다.
- DAO에서 전체 대상의 존재/삭제 여부를 확인하고 하나의 트랜잭션으로 삭제한다. 기존 단건 삭제와 같은 외래키 연결 정리 및 동기화 삭제 기록을 사용한다.
- 오류 시 선택을 유지하고, 편집 패널이 접혀 있어도 작업바에 오류를 표시한다.
- 조회 변경/결과 소멸로 선택 세션이 끝날 때 처리 상태도 초기화한다.

검증:

- `flutter analyze --no-pub`: 문제 없음.
- `flutter test --no-pub test/data/bulk_transaction_delete_test.dart test/ui/transaction_selection_test.dart test/ui/daily_convenience_test.dart test/data/daily_convenience_test.dart`: 25개 통과.
- PC/모바일 확인·취소·선택 행만 삭제, 선택 없음 비활성화, 실패 시 선택 유지/오류 표시, DB 오류 시 거래·태그 연결·동기화 기록 전체 롤백을 검증했다.
