# My Little Budget 1.0.0-rc.4 (build 55)

- PC·모바일 선택 모드에 거래 삭제 버튼을 추가했습니다.
- 삭제 전 건수와 수입·지출 합계를 확인하며, 이체는 별도 합계로 표시합니다.
- 취소하면 선택을 유지하고, 삭제 오류가 발생하면 일부만 삭제되지 않도록 처리합니다.
- PC 내역에서 예산·투자로 이동했을 때 제목 옆 `<` 버튼으로 돌아갈 수 있습니다.
- 제목은 한 번만 표시되며, 제목 글자가 아닌 `<` 버튼을 눌러야 돌아갑니다.
- 돌아왔을 때 내역의 조회 조건, 입력 내용과 스크롤 위치를 유지합니다.
- 제목 옆 뒤로가기 버튼은 PC 화면에만 적용하며 모바일 화면은 기존 동작을 유지합니다.

Android 버전 코드 **55**는 사용자의 요청에 따라 유지했습니다. 이전 AAB를 Play Console에 아직 업로드하지 않은 상태를 기준으로 새 AAB를 생성했습니다.

- Android: `MyLittleBudget-Android-1.0.0-rc.4.aab`
- Windows 신규 설치: `MyLittleBudget-Setup-1.0.0-rc.4.exe`
- Windows 앱 내 업데이트: `MyLittleBudget-Update-1.0.0-rc.4.exe`
- 파일 검증값: `SHA256SUMS.txt`

Google Play Console 업로드/출시와 로컬 PC 앱 설치는 이번 GitHub 배포에 포함하지 않았습니다.
