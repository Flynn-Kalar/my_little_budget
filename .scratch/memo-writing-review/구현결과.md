# 메모 작성·편집 개선 구현 기록

작성일: 2026-10-16, 한국 시간

## 적용 내용

- 기존 Flutter Quill 편집기와 일반 메모·금액 목표·불릿·체크리스트·본문 기본 크기 18 유지.
- 저장하지 않은 변경이 있는 경우 취소·뒤로가기·바깥 클릭에서 계속 작성 / 변경사항 버리기 / 저장 후 닫기 제공.
- 편집 후 원래 값으로 되돌아오면 별도 확인 없이 종료. 저장 중에는 중복 저장·이탈 제어.
- DB 저장 실패 시 입력과 초안 유지, 재시도 가능. 저장 후 닫기가 메모장 화면까지 닫지 않도록 중복 종료 방지.
- 초안은 입력이 멈춘 뒤 약 1초 후, 앱 비활성화·백그라운드 전환 시에도 저장 시도. 상태에 실제 저장 성공 여부 표시.
- 새 메모는 다시 새 메모를 열 때, 기존 메모는 다시 편집할 때 복구 / 초안 버리기 / 나중에 선택 제공. ‘나중에’는 현재 편집 화면을 닫고 초안을 유지.
- 제목이 없거나 금액·반복 간격이 입력 도중인 초안도 보관. 서식·금액 목표·미적용 추가 금액·날짜·고정·일정·알림 설정 포함.
- 원본의 수정 시각이 달라졌거나 원본이 삭제되면 자동 덮어쓰기를 막고 ‘새 메모로 저장’ 제공. 모바일의 추가 알림 옵션이 포함된 초안도 PC 작성 화면에서 보존.
- PC·모바일 모두 일정·알림을 ‘추가 설정’으로 정리. PC 대화상자와 shell 정책 유지. 모바일은 저장·취소와 상태 표시를 스크롤 영역 밖에 고정.
- 모바일 작성 시트는 드래그로 닫기를 막고, 취소·뒤로가기를 통해 내용 보호 절차 적용.
- 실행 취소·다시 실행 버튼과 활성 상태 추가. 모바일은 체크리스트·불릿·형광펜을 기본 도구 모음에, 글자 크기·기타 서식을 더보기에 배치.

## 저장과 데이터 호환

- 스키마 21에서 `note_drafts` 테이블 추가. 이전 메모 테이블과 본문 형식은 변경하지 않음.
- 초안 쓰기는 메모 저장 및 알림 예약 경로와 분리. 최종 저장 전 초안 쓰기 완료를 기다려 오래된 비동기 쓰기가 초안을 되살리지 않도록 처리.
- 최종 저장 시 동일 트랜잭션에서 원본 버전 확인 → 메모 저장 → 해당 초안 삭제. 실패 시 초안 삭제도 롤백.
- 최종 저장용 본문·리치 본문·체크리스트를 같은 문서 스냅샷에서 생성.
- 초안은 로컬 복구용이며 전체 백업에 포함하지 않음. 백업 복원·전체 초기화 시 새 메모 초안을 포함해 제거. 기존 메모 삭제 시 연결된 초안은 외래 키로 함께 제거.
- 초안 읽기가 실패하면 원본 초안을 유지하고 실패 상태 표시. 성공하지 않은 임시 저장을 완료로 표시하지 않음.

## 검증 항목

- 새 메모와 기존 메모의 초안 복구, 제목 없는 초안, 서식·목표·날짜·고정·일정·알림 옵션 보존.
- 변경 취소·뒤로가기 확인, 원상 복구 시 확인 생략, 저장 후 닫기와 제목 검증.
- DB 오류를 주입한 저장 실패 및 재시도, 다른 화면에서 수정된 원본 보호와 복사 저장.
- 앱 비활성화 시 임시 저장, 모바일 키보드 표시 시 저장 버튼 접근, 실행 취소·다시 실행.
- 초안 저장으로 원본·체크 항목·알림이 변경되지 않음, 백업/복원 정책, 버전 20 업그레이드 및 DB 재개방 후 복구 데이터 보존.
- 기존 메모 기능과 다른 화면은 전체 테스트로 회귀 확인. 플랫폼 빌드 결과는 최종 응답에 기록.

최종 검증 결과: `flutter analyze` 무오류, 전체 테스트 394개 통과, Windows release 빌드 성공, Android debug APK 빌드 성공. 실제 기기에서의 수동 조작이나 Play 업로드는 이번 검증에 포함하지 않음.

## 한계와 후속 범위

- 초안은 ‘이 기기에 임시 저장됨’ 표시가 나온 시점의 로컬 데이터다. 강제 종료 순간의 마지막 입력까지 보장하지 않으며 클라우드 동기화 완료를 의미하지 않는다.
- 새 메모의 복구 슬롯은 기기 DB당 하나다. 기존 메모는 메모 ID별로 별도 초안을 보관한다.
- 폴더·메모 태그·첨부·전문 검색·메모 단위 동기화는 이번 범위에 포함하지 않았다.
- 이번 작업 시작 전 존재하던 알림 안정화·통계 등의 수정은 보존했다. 이 기록은 해당 별도 작업 전체를 구현했다고 주장하지 않는다.
