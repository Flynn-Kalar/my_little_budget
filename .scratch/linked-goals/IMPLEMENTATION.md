# 목표 자동 집계와 목적별 자금

Status: ready-for-human

2026-11-18 구현 완료. 배포·커밋·태그·GitHub 게시 없이 작업 폴더에 반영했다. 기존 카드 사용액/청구 기능 변경 및 작업 시작 시 존재한 pubspec 버전 변경을 유지했다.

## 사용 방법

- 메모의 금액 목표 삽입/수정에서 집계 방식을 선택한다. 직접 입력, 계좌 잔액 자동 집계, 연결 계좌 거래 자동 집계를 지원한다.
- 거래 방식에서는 시작 금액과 시작일을 지정하고, 선택적으로 태그를 고른다. 입금·이체 입금은 더하고 지출·이체 출금은 차감한다. 조정 거래도 부호대로 반영한다.
- 목표일을 지정하면 이번 달 필요한 적립액을 표시한다. 달력 월 기준이며 월초 부족액을 남은 달 수로 나누고 이번 달 순적립액을 차감한다. 이미 이번 달 몫을 모았으면 0원이다.
- 자산 편집의 자금 용도에서 생활비·비상금·연간 지출 준비금을 선택한다. 계좌 전체 잔액의 구분이며, 자산 요약과 목록·상세에 표시한다. 준비금은 생활비 잔액에 더하지 않으며 전체 순자산은 유지한다.

## 데이터와 호환성

- 목표 연결은 메모 본문 목표 블록 JSON의 source/accountUuid/tagUuid로 저장한다. 동기화 시 기기별 정수 ID 차이에 영향을 받지 않는다.
- Drift schema 28에 nullable accounts.fund_purpose를 추가했다. 이전 백업은 생활비로 표시하며, 이전 앱의 동기화 항목에 필드가 없으면 기존 설정을 보존한다.
- 거래·태그·계좌 스트림으로 진행률을 갱신한다. 미래 거래는 제외하고, 계좌 잔액 수정은 오늘의 adjustment를 통해 반영한다. 저장된 목표 시작 금액은 실시간 집계로 덮어쓰지 않는다.
- 보관 계좌는 집계를 유지하고 상태를 표시한다. 연결 계좌·태그가 없으면 안내를 표시하며 임의의 0원으로 표시하지 않는다.
- 카드·투자 자산은 목표 연결에서 제외한다. 준비금 용도는 투자 자산이 아닌 현금·은행 계좌에만 지정한다.
