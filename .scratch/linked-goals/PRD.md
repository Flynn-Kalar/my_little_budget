# 목표 자동 집계와 목적별 자금

Status: ready-for-human

2026-11-18 요청: 목표를 계좌·거래에 연결해 자동 집계하고 이번 달 필요한 적립액 표시. 비상금·연간 지출 준비금을 생활비와 구분.

- 기존 메모 본문의 금액 목표를 확장한다. 수동 입력은 유지하며, 계좌의 오늘 잔액 / 시작일 이후 연결 계좌 거래의 순적립액(선택 태그 필터)을 고를 수 있다. 연결은 UUID로 저장한다.
- 계좌 잔액 모드는 초기 잔액과 오늘까지의 거래를 합산한다. 거래 모드는 입력 시작 금액 + 시작일부터 오늘까지 입금·출금·이체·조정의 순액을 집계한다. 미래 거래를 현재 적립액에 포함하지 않으며, 수정·삭제·동기화도 즉시 반영한다.
- 이번 달 필요 적립액: 이번 달 초 부족액을 목표일까지 남은 달 수(이번 달 포함)로 올림 나누고 이번 달 순적립액을 차감한다. 기한 경과는 남은 금액 전부, 달성은 0, 목표일 미설정은 안내로 표시한다. 수동 목표는 현재 남은 금액을 기준으로 추정한다.
- 계좌를 생활비 / 비상금 / 연간 지출 준비금으로 지정한다. 용도별 오늘 잔액을 자산 화면에서 별도 합산하며 준비금은 생활비 금액에 더하지 않는다. 전체 계좌 잔액의 구분이며 가상 이체나 이중 차감을 만들지 않는다. 카드·투자 자산은 준비금 지정 대상이 아니다.
- 목표 링크는 기존 richContent와 함께 백업·동기화한다. 계좌 용도는 선택적 컬럼을 추가하고 구 백업·동기화와 호환한다. 연결 계좌/태그가 없으면 0으로 속이지 않고 연결 확인 안내를 표시한다.
- 기존 신용카드 사용액/청구 기능과 작업 중 버전 변경을 유지한다. 이번 요청은 배포 요청이 아니다.

검증: 월별 적립 계산/기한/음수 수동 목표, 계좌 및 거래 연결, 태그·이체 중복 방지, 미래 제외, 수정·삭제 자동 갱신, 구 데이터 마이그레이션/백업/동기화, PC·모바일 설정과 표시.
