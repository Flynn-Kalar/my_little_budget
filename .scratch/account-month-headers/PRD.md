# 자산 거래내역 제목·월·날짜 헤더

Status: ready-for-human

- 모바일 자산 상세의 목록 위에 `자산 거래내역` 제목(20)을 추가한다.
- 모바일의 거래를 날짜별로 묶고 날짜·요일 헤더(13)를 추가한다.
- PC·모바일 모두 `2026년 10월` 형태의 월 헤더(18, 굵게, 연한 강조 배경)를 추가한다.
- 같은 월은 한 번만 표시하고 연도가 다르면 구분한다.
- 최신순 정렬과 같은 날짜 내 기존 순서, 잔액, 편집, 필터, PC 초기 잔액 표시는 유지한다.
- 일반 거래·이체·잔액 조정·투자 가상 행은 기존 조회 결과를 그대로 월/일에 묶어 표시한다.
- 필터링된 결과만 묶으며 빈 결과에는 월/일 헤더를 표시하지 않는다.
- PC와 모바일의 목록은 각각 수정하고 월 헤더 표시 위젯만 공유한다.

검증: 연도 경계/같은 날짜 중복/월별 정렬/기간 필터/빈 결과를 PC·모바일에서 확인. 정적 분석 문제 없음.

이번 변경은 로컬 소스에 반영하며 별도 AAB 생성이나 GitHub 푸시는 수행하지 않는다.
