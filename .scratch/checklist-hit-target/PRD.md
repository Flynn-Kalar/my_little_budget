# 체크리스트 체크 영역 확대

Status: complete (local source)

- PC와 모바일의 공용 메모 편집기·뷰어에서 체크박스 그림만 클릭되던 문제를 수정한다.
- 체크 항목 왼쪽 영역을 최소 48픽셀 너비로 확보하고 행 높이도 최소 48픽셀로 렌더링한다. 작은 글자와 들여쓰기에도 적용하며 문서의 저장된 서식·체크리스트 내용은 바꾸지 않는다.
- 실제 클릭 영역을 채우는 InkWell을 사용하고 24픽셀 체크 표시를 중앙에 둔다. 모서리 클릭도 체크 변경으로 처리하여 바깥의 본문 편집 동작이 실행되지 않는다.
- 일반 글머리·숫자 목록의 간격은 유지한다. 본문 탭 편집과 링크 recognizer도 유지한다.
- 관련 38개 테스트 통과: 터치·마우스, 영역 네 모서리, 작은 글씨·들여쓰기, DB 체크 저장·취소, 본문 탭 편집과 기존 메모 편집 회귀.
