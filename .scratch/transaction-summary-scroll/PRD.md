# PC 거래 내역 요약 카드 자동 접기

Status: complete (local)

거래 목록을 아래로 스크롤하면 수입·지출·순수입 카드만 접고 위로 스크롤하면 복원한다. 180ms 크기 애니메이션으로 목록 영역을 늘린다.

제목, 월 선택, 검색·필터, 프리셋, 입력창과 선택 도구는 유지한다. 기존 상단 전체 접기 버튼은 유지하며 수동으로 펼치면 요약 카드도 복원한다. 목록의 실제 사용자 세로 스크롤에만 반응하고 프로그램에 의한 이동이나 레이아웃 변화는 무시한다. 모바일 UI는 변경하지 않는다.

검증: PC 폭 1000/1400에서 마우스 휠·드래그 양방향, 목록 높이 증가, 입력 초안과 선택 유지, 프로그램 이동 시 미접기 확인. 기존 내역·거래 선택·좌우 정렬·compact desktop 포함 관련 33개 테스트 통과. 배포는 수행하지 않는다.
