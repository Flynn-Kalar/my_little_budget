# 태그 추천 정렬과 PC Enter 입력 흐름

- 모든 태그를 표시하며 분류 미선택 시 전체 거래 사용 횟수순으로 정렬한다.
- 분류를 선택하면 해당 분류에 연결된 태그를 먼저 모으고 분류 내 사용 횟수순, 최근 거래 일시순으로 배치한다. 나머지는 전체 거래 사용 횟수순이다.
- 선택/해제 도중 태그 순서와 버튼 위치를 고정한다. 분류 변경 시에는 새 분류의 순서를 적용한다.
- PC 빠른 입력에서 `게임` + Enter → `게임, `, `게임, 스팀` + Enter → `게임, 스팀, `로 만들고 태그 입력에 머문다.
- 빈 입력 또는 쉼표 뒤 빈 다음 태그에서 Enter를 누르면 내용으로 이동한다.
- 자동완성으로 다음 태그를 확정해도 앞에서 입력한 태그를 유지하고 같은 태그를 중복 추가하지 않는다.
- PC/모바일 UI 구조를 유지하고 이 작업에서는 설치본 배포를 하지 않는다.
