# 내역 목록 안에서 다중선택 및 일괄 수정

Status: ready-for-agent

- PC와 모바일 모두 평소 체크박스를 숨긴다.
- 내역을 길게 누르면 해당 내역을 선택하고 선택 모드에 진입한다. 일반 클릭/터치는 기존 단건 편집을 유지한다.
- 선택 모드에서는 클릭/터치로 선택을 토글하고 PC는 Shift로 보이는 목록 순서의 범위를 추가 선택한다.
- 별도 팝업에서 내역을 다시 선택하지 않는다. 기존 목록의 작업바에서 선택 건수/수입·지출 합계, 조회 결과 전체 선택, 선택 해제, 종료를 제공한다.
- 카테고리/태그 입력은 작업바 안에서 펼치며 기존 원자적 일괄 수정 기능을 사용한다. 적용 후 남아 있는 내역의 선택을 유지한다.
- 조회 월/검색/필터를 변경하면 선택을 종료해 다른 조회 결과에 선택이 섞이지 않게 한다.
- PC/모바일 목록 UI를 각각 수정하고 shell/플랫폼 정책은 유지한다.
- 이 작업은 코드 개선 범위이며 빌드·설치·GitHub 배포 요청을 포함하지 않는다.
