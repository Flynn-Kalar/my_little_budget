# 구현 결과

- PC 빠른 입력·편집/복사와 모바일 입력·편집/복사에 예산 미리보기 추가. 모바일 계산기에도 실시간 표시.
- 금액·날짜·계좌·카테고리를 반영하고 거래 날짜의 집계 기간 사용. 수정은 기존 거래를 조회에서 제외하고 복사는 새 지출로 계산. 예정 지출, 소득 비율, 조정액, 자산 연동 계산을 그대로 재사용.
- 그룹별 입력 후 잔액, 초과액, 남은 기간 하루 금액 표시. 과거 기간은 하루 금액 생략. 그룹 합산 없음. 빈 금액·미완성 식·조회 실패는 숫자를 추정하지 않고 안내.
- 초과한 카테고리 예산은 다른 카테고리 예산에서 가져오기 제공. 이동은 명시적인 버튼으로 즉시 저장되며 거래 저장과 별개임을 안내. 같은 기간의 카테고리 예산만 허용하고 실제/입력 후 잔액을 재검사. 두 그룹의 조정액을 단일 트랜잭션으로 저장. 자산 연동 그룹은 제외.
- 모바일 메모는 항상 표시. 날짜·시간은 값이 보이는 접힌 버튼으로 시작. 저장 도구는 입력 스크롤 밖에 배치. 작은 화면과 키보드 영역 확보.
- 명시적으로 연결한 카테고리 태그만 펼침. 나머지는 수동 펼치기. 카테고리 변경 시 다른 태그는 접고 기존 선택은 유지하며 해제 가능. PC 태그 Enter 흐름과 모바일 계산기 유지.
- 기존 작업 중인 파일 구조 개편 등은 보존. 버전 변경·배포·GitHub 게시 없음.

- 전체 lib/test 정적 분석 통과. 변경 내용 공백 검사 통과.
- 거래 수정/복사, 집계 경계, 과거/미래, 예정 지출, 겹치는 그룹, 자산 연동, 비율 예산, 원자적 예산 이동, DB 변경 반영 검증.
- 390×844 및 360×640 모바일, 다수 태그·키보드·저장 위치, PC 입력/편집/좁은 네이티브 데스크톱 동작 검증.
- 시스템 한글 글꼴과 Material 아이콘으로 모바일 입력 및 계산기 화면을 렌더링해 간격·잘림 확인. PNG는 이 디렉터리에 보관. 실제 설치 앱에서 수동 검증/릴리스 빌드는 수행하지 않음.
