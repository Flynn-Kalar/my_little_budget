# 입력 중 예산 확인

- PC 빠른 입력·거래 편집/복사와 모바일 입력·편집/복사에 저장 전 예산 미리보기를 제공한다.
- 거래 날짜의 집계 기간과 기존 예산 산식을 사용한다. 수정은 원거래를 제외하고 계산하며 복사는 새 지출로 계산한다.
- 관련 카테고리/자산 예산별 남은 금액, 입력 후 잔액, 하루 사용 가능액 및 초과액을 표시한다. 중복 그룹을 합산하지 않는다. 잘못되거나 미완성인 금액은 계산하지 않는다.
- 초과한 카테고리 예산은 다른 카테고리 예산에서 금액을 이동할 수 있다. 자산 연동 예산은 실제 자산 흐름이므로 임의로 이동하지 않는다. 이동은 사용자 버튼으로 즉시 저장되며 거래 초안은 유지한다.
- 모바일 메모는 항상 펼친다. 날짜·시간은 접힌 상태로 시작하며 현재 값은 접힌 제목에 표시한다. 저장 버튼은 스크롤 밖 하단에 유지한다. 기존 계산기에서도 입력 중 예산을 표시한다.
- 선택 카테고리에 명시적으로 연결된 태그만 자동으로 펼친다. 다른 태그/미지정 태그는 접고 수동 펼치기를 제공한다. 카테고리 전환 시 다시 접되 선택한 태그는 보존하고 삭제 가능하게 표시한다.
- PC/모바일 화면 분리를 유지하며 공통 계산과 재사용 가능한 표시만 공유한다. 기존 작업 중인 변경을 보존한다. 배포 요청은 없으므로 빌드/릴리스 게시하지 않는다.

검증: 생성/수정/복사, 집계 경계·과거/미래·계좌 이동, 금액 식·초과, 예산 이동 원자성, 태그 전환/선택 보존, 좁은 화면·키보드·계산기·저장 흐름.
