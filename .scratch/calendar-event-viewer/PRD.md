# 캘린더 일정 읽기 화면

Status: complete (local source)

- 기존 일정은 먼저 읽기 전용 상세 화면에서 제목·일시·내용·장소·링크·반복·시간대·D-day·알림 설정을 표시한다.
- PC는 상세 대화상자, 모바일은 상세 시트를 사용한다. 긴 내용은 스크롤하고 수정 버튼은 별도로 유지한다.
- 월간 일정, 날짜별 일정 목록, D-day 모아보기, 일정 바로가기에서 동일하게 적용한다.
- 수정 버튼을 누르면 기존 편집기로 이동한다. 반복 회차는 기존 회차별 수정·전체 수정·건너뛰기를 유지한다.
- 빈 날짜와 일정 추가는 기존 새 일정 입력 흐름을 유지한다. 읽거나 닫는 작업으로 데이터를 수정하지 않는다.
- 최초 구현은 로컬 코드에 반영했다. 후속 요청에 따라 rc.9(58) 배포에 포함한다.

## 검증

PC·모바일의 상세 보기 → 닫기/수정, D-day 편집, 반복 회차 편집·건너뛰기·복원 및 빈 날짜 추가 흐름을 확인한다.

- 관련 UI 테스트 6개 통과. 상세 화면에 입력란이 없고 닫아도 DB가 바뀌지 않는지 확인했다.
- 정적 분석 문제 없음. GitHub 푸시·설치본 업데이트·AAB 재생성은 수행하지 않았다.
