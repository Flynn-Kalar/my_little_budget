# 캘린더 날짜 선택과 D-day

Status: ready-for-human

## 요구 사항과 동작

- PC·모바일의 월간 캘린더에서 날짜 칸 전체를 클릭/터치할 수 있다.
- 비어 있는 날: 선택 날짜가 채워진 일정 추가창을 연다.
- 일정이 있는 날: 해당 날짜의 전체 목록을 열며 목록 항목에서 편집하고 일정 추가도 가능하다.
- 목록에는 기존에 캘린더에 표시하던 반복 회차, 메모, 공휴일도 포함한다. 메모는 메모 편집으로 연결한다.
- 격자에 보이는 이전/다음 달 날짜도 해당 달의 일정 정보를 이용한다. 월간 하단/옆 목록은 기존처럼 선택한 달만 표시한다.
- 일정 추가/수정에서 D-day를 켜거나 끌 수 있다. 시작 날짜를 기준으로 미래 D-n, 당일 D-day, 과거 D+n을 표시한다.
- 반복 일정의 D-day도 시리즈 시작 날짜가 기준이다. 시간 차이가 아닌 날짜 차이로 계산한다.
- 캘린더 상단 월간 / D-day 전환에서 지정한 모든 달의 일정을 모아 본다. 오늘·가까운 미래 순, 과거는 최근 순으로 표시한다.
- D-day 목록의 항목은 수정창을 연다. 지정 해제·삭제 후 자동 갱신한다. D-day 보기에서 추가하면 기본적으로 D-day가 켜진다.

## 저장과 기존 기능

- 기존 calendar_events.schedule_data JSON에 선택 필드 dday를 추가한다. 이전 데이터는 false로 읽으므로 스키마 변경은 없다.
- 일반 편집, 반복 예외 편집, 알림의 기기 시간대 확정에서 D-day를 보존한다.
- 기존 백업 및 증분 동기화의 schedule_data 경로로 함께 보존한다.
- PC와 모바일 화면은 각 폴더에서 유지하고 날짜 목록·카운터·D-day 목록 위젯만 공유한다.
- 첨부된 삼성 캘린더 분석보고서는 참고 자료로 읽었다. 삼성/Google 시스템 일정 동기화, 알림 정책 이식은 이번 요구 범위에 포함하지 않는다.

## 검증

- 전체 테스트 503개 통과, 정적 분석 문제 없음.
- PC·모바일 날짜 선택, 해당 날짜 추가/목록/편집, D-day 저장·모아보기·지정 해제·삭제.
- 월과 연도를 넘는 목록, 당일/연말/윤일 계산, 반복 예외 및 알림 처리 중 보존, 백업·동기화.
