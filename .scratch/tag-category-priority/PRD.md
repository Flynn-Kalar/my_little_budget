# 태그 카테고리 지정과 추천 순서

Status: ready-for-human

## 요구 사항

- PC와 모바일의 설정 > 태그 관리 > 추가/수정에서 카테고리를 여러 개 지정한다.
- 거래 카테고리 미선택 시 모든 태그를 전체 거래 사용 횟수순으로 표시한다.
- 거래 카테고리 선택 시 명시적으로 지정된 태그를 먼저 표시하고 나머지를 뒤에 표시한다. 각 그룹은 전체 거래 사용 횟수순이다.
- 동률은 최근 거래 일시, 수동 순서, ID 순으로 정한다. 삭제된 거래는 사용 횟수에서 제외한다.
- 태그 선택/해제 중에는 현재 순서를 유지하고 카테고리를 바꾸면 다시 정렬한다.
- 기존 태그는 카테고리 미지정으로 시작한다. 과거 거래에서 카테고리를 추론해 자동 지정하지 않는다.

## 구현

- 스키마 23: tags.category_ids_json에 정렬·중복 제거된 로컬 카테고리 ID 목록 저장.
- 증분 동기화에서는 category_uuids로 변환하고 수신 기기의 로컬 ID로 복원한다.
- 이전 동기화 클라이언트의 필드 누락은 기존 지정을 유지한다. 이전 백업은 빈 목록으로 읽는다.
- 카테고리 영구 삭제 시 관련 태그 지정도 정리한다. 보관된 기존 지정은 편집창에서 표시하고 해제할 수 있다.
- 공통 카테고리 선택 위젯만 공유하고 PC와 모바일의 태그 화면은 각각 유지한다.

## 검증

- PC·모바일 다중 지정 저장 및 편집 복원, 추천 그룹/빈도 정렬, 선택 중 순서 유지.
- v22 마이그레이션, 백업 왕복과 이전 백업, 잘못된 값 거부, 카테고리 삭제 정리.
- 서로 다른 기기 로컬 ID로 동기화 및 이전 payload 호환.
- 전체 테스트 492개 통과, 정적 분석 오류 없음.
