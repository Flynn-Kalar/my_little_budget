# 일정 시간대 검색과 표시

Status: complete (local source)

- PC와 모바일 일정 폼의 원시 시간대 입력을 입력·검색 가능한 드롭다운으로 교체한다.
- 지역명 / UTC ±N 형식으로 표시하고, 30분·45분 차이도 표기한다. 일정 날짜의 서머타임을 반영한다.
- 한국어 주요 지역명, 영문 도시명, IANA 이름과 주요 지역의 현지 표기(東京, 上海, Москва, دبي 등)로 검색한다. UTC 시간 차이로도 필터링한다.
- 저장 값은 IANA 식별자를 유지한다. 기존 고정 오프셋 시간대는 지역을 추측하지 않고 고정 시간대로 표시한다.
- 새 일정은 기기의 시간대를 기본값으로 사용한다. Android 알람 채널이 없는 PC 등에서는 기존 flutter_timezone 플러그인으로 실제 기기 지역을 조회한다. 기기에서 조회한 비정수 시차 지역도 식별자를 그대로 사용한다.
- 기존 일정의 시간대를 덮어쓰지 않으며, 기기 시간대가 늦게 도착해도 사용자가 입력한 값을 덮어쓰지 않는다.
- 관련 18개 테스트 통과: 표시·서머타임·분 단위 차이·자국어 검색·320/1000폭 입력/선택·기기 시간대 조회·기존 일정 반복 회귀.
- 전체 테스트 570개 통과, 정적 분석 문제 없음.
