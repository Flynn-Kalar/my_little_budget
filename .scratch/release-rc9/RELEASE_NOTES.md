# 나만의 작은 가계부 1.0.0-rc.9 (58)

## 변경 사항

- 캘린더 일정은 먼저 읽기 전용 상세 화면으로 열립니다. 제목·일시·내용·장소·링크·반복·D-day·알림 설정을 확인하고 '수정' 버튼으로 편집할 수 있습니다.
- PC와 모바일의 월간 일정, 날짜별 목록, D-day와 일정 바로가기에 같은 흐름을 적용했습니다. 반복 일정의 이번 회차·전체 수정 및 건너뛰기 기능을 유지합니다.
- 메모를 Supabase 증분 동기화에 추가했습니다. 제목·본문·서식·체크리스트와 완료 상태·목표·고정·캘린더 표시·반복 일정을 공유합니다.
- 메모 알람 켜기·시각·사전 알림·소리·진동·다시 알림·전체 화면 모드는 각 기기에만 저장합니다. 새로 받은 메모는 알람이 꺼져 있고, 기존 메모의 기기별 알람 설정은 유지합니다.
- README의 다운로드 링크·기능·UI 정책·동기화·설치 및 배포 안내를 갱신했습니다.

## Supabase 사용 시 필요한 작업

모든 기기를 rc.9 이상으로 업데이트하고, [최신 서버 SQL 전체](https://github.com/Flynn-Kalar/my_little_budget/blob/v1.0.0-rc.9/supabase/table_sync_v2_schema.sql)를 SQL Editor에서 다시 실행하세요. 기존 데이터는 유지하며 메모용 `mlb_notes`를 추가합니다. 실행 결과가 **11 / 11**인지 확인한 뒤 앱에서 동기화하세요. 서버 SQL은 앱 업데이트만으로 자동 적용되지 않습니다.

이미 여러 기기에서 사용하던 메모 알람은 각 기기에 그대로 남습니다. 알람이 필요 없는 기기에서만 꺼주면 다른 기기의 설정은 유지됩니다.

## 검증 및 파일

- 전체 테스트 531개 통과, 정적 분석 문제 없음.
- Windows Setup.exe와 Update.exe는 같은 전체 설치 패키지이며 기존 AppId와 데이터 위치를 유지합니다.
- Android AAB는 Google Play 업로드용 서명 번들입니다. versionCode는 58입니다. GitHub 게시와 Google Play 배포는 별개입니다.
- SHA256SUMS.txt로 두 Windows 설치 파일과 Android AAB를 검증할 수 있습니다.
