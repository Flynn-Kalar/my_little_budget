# 구현 결과

- `cardSpendingPeriod`에서 마감일 포함, 다음 날 전환, 달에 없는 날짜의 말일 보정을 공통 처리한다.
- 카드 요약과 편집은 카드 마감일을 우선해 거래일 기준 사용액을 계산한다. 설정 미완료 카드는 공통 기간을 유지한다. 결제월을 무조건 한 달 미루는 해석은 제거했다.
- 마감일과 사용액을 동시에 바꿀 때 새 기간 기준으로 차액을 계산한다. 카드 금액을 건드리지 않은 설정 저장은 조정 거래를 추가하지 않는다.
- PC와 모바일 카드 거래행에 `기간 사용액`과 `미결제 잔액`을 구분한다. 카드 요약에 실제 사용액 집계 시작일·종료일도 표시한다. 원장 잔액과 순자산 계산은 유지한다.
- 첨부 수치 재현은 테스트 전용 데이터에서 수행했다. 과거 상환 11,368원을 이용해 차이를 재현했으며 이것이 사용자 원장의 실제 원인이라고 가정하지 않는다. 실제 사용자 DB는 열거나 수정하지 않았다.
- 스키마/버전 변경과 배포 없음. 자동 정산 이체 생성은 추가하지 않음.
