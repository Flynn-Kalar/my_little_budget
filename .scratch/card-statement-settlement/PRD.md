# 카드 마감일 포함 집계와 사용액 수정 표시

Status: ready-for-human

2026-11-19 최종 사용자 정정: **마감일 당일까지 이전 집계월, 마감일 다음 날부터 새 집계월**로 계산한다. 결제월의 전월로 마감일을 무조건 이동하라는 뜻이 아니다. 사용액 수정 대상은 청구금액이 아닌 거래일 기준 사용액이다.

- 카드별 사용액 기간은 직전 마감일 다음 날부터 이번 마감일 당일까지다. 10일 마감: 10/11~11/10, 다음 기간 11/11~12/10. 말일 마감: 10/1~10/31, 11/1~11/30. 2월과 윤년도 같은 규칙을 적용한다.
- 카드 마감일이 설정되면 공통 집계 시작일보다 카드 마감일을 우선한다. 미설정 카드는 기존 공통 집계기간을 유지한다. 은행·현금과 다른 화면의 공통 기간 설정은 유지한다.
- 오늘까지 사용액, 예정 거래를 포함한 기간 사용액, 사용액 수정, 거래행 누적 사용액이 같은 기간을 사용한다. 초기 잔액과 상환 이체는 사용액에서 제외한다.
- 첨부 사례: 431,210 - 16,019 = 415,191은 사용액이며, -419,842 + 16,019 = -403,823은 누적 잔액이다. 화면에서 두 값의 의미를 구분하고 데이터에 임의의 추가 보정을 하지 않는다. 차이 11,368원의 실제 원인은 첨부만으로 확정하지 않는다.
- 마감일 변경과 사용액 수정이 함께 저장되면 새 기간을 기준으로 수정한다. 금액을 변경하지 않은 카드 설정 편집은 조정 거래를 만들지 않는다.
- 결제일에 대응하는 청구/할부 일정은 기존의 직전 마감일 기준을 유지한다. 결제일 휴일 이동은 사용액 기간을 바꾸지 않는다.
- 정산은 은행→카드 이체로 기록하면 은행 잔액과 카드 부채가 줄고 지출은 중복되지 않는다. 현재 앱은 결제일만으로 이체를 자동 생성하지 않는다. 이번 마감 기준 수정에 자동 정산 기능을 추가하거나 과거 정산을 소급 생성하지 않는다.
- 이전 아이콘 설치 정책 변경은 유지하며 이번 요청만으로 배포하지 않는다.
