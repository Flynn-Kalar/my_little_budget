# 모바일 통계 카테고리별 태그 비율

## 요구사항과 구현

- 모바일 월별 통계의 카테고리 행 또는 도넛 조각을 선택하면 하단 태그 비율 뷰어를 연다.
- 선택한 월·카테고리를 별도 쿼리 키로 고정해 데스크톱 선택 상태에 영향을 주지 않는다.
- 태그별 도넛, 금액, 비율, 비율 막대와 태그 없음을 표시한다. 기존 expenseByTag 집계를 사용하며, 여러 태그를 가진 거래는 정렬 우선 태그 하나에 귀속한다.
- 로딩·오류 재시도·빈 결과·닫기·목록 스크롤을 지원한다.
- 카테고리 도넛에 모든 카테고리를 포함해 합계와 그림의 분모가 일치하도록 한다.
- 모바일 UI만 변경한다.

## 검증

- 실제 메모리 DB 기반 위젯 테스트에서 선택 월/카테고리 분리, 75%/25%, 태그 없음, 닫은 뒤 다른 카테고리 재선택을 검증했다.
- 관련 모바일 위젯 테스트 총 4개 통과.
- flutter analyze 이상 없음.
