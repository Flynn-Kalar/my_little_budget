# 카드 할부 입력과 청구 일정

Status: ready-for-human

2026-11-18 요청: 배포된 앱에 할부 결제가 없음. PC·모바일 카드 지출 입력/수정/복사에 할부 기능을 추가한다. 이번 요청은 기능 보완이며 별도 배포 요청은 아니다.

- 카드 지출에서 일시불 또는 2~60개월을 선택한다. 입력 금액은 총 구매금액이며 예산·통계·카드 부채에 한 번만 반영한다.
- 2026-11-19 추가 요청: 결제수단이 신용카드일 때만 할부 결제를 활성화한다. 다른 결제수단 또는 수입·이체로 바꾸면 선택을 해제한다. 프리셋에도 같은 규칙을 적용한다.
- 총 원금을 개월 수로 나누고 1원 단위 나머지는 첫 회차에 더한다. 수수료는 별도 지출로 입력한다.
- 카드 결제일·마감일로 첫 청구 주기를 찾고 월별 청구 일정을 계산한다. 말일·휴일 이동을 반영하고 다음 회차는 이전 회차의 잘린 날짜가 아닌 원래 결제일을 기준으로 계산한다.
- 이번 결제일/이후 청구액을 할부 일정에 맞춰 분리한다. 카드 화면에는 거래별 이번 청구 회차·회차 원금·이후 청구될 잔여 원금을 표시한다. 회차별 표시는 청구 예정 원금이며 상환·환급은 카드 전체 예상 청구액에 반영한다. 날짜가 지났다는 이유로 납부 완료로 처리하지 않는다.
- 거래 목록/자산 상세에 할부 표시를 추가하고, 수정·복사·삭제 및 백업·동기화에서 개월 수를 유지한다. 기존 거래/백업은 일시불로 해석한다. 카드 설정이 없으면 설정 필요를 안내한다.
- 실거래를 복제하지 않고 원거래의 할부 개월 수만 저장한다. 미래 회차를 별도 지출로 중복 생성하지 않는다.
- 검증: 원 단위 합계, 결제/마감 경계, 월말·휴일·연도 전환, 상환·환급·기한 경과, 저장/수정/복사/삭제, 구 데이터/백업/동기화, PC·모바일 입력과 표시 및 기존 기능 회귀.
