# rc.16 배포 범위

- 사용자 첨부 화면의 다중 선택 도구가 하단 내비게이션 및 모달 위에 겹치는 문제를 수정한다.
- 선택 도구는 화면 내부에서 실제 크기만큼 영역을 확보한다. 고정 160px 여백과 root overlay를 제거하고, 작은 화면/큰 글꼴에서는 도구 영역을 스크롤할 수 있게 제한한다.
- 태그 지정 카테고리를 지출/수입 섹션으로 분리한다. 기존 카테고리 ID 및 다중 선택·추가·교체·해제 동작을 유지한다.
- 기존 품질 점검의 동기화/선택 월 수정도 포함한다.
- 모바일/PC 화면 폴더 분리는 유지하며 공용 선택 위젯을 수정한다.
- 회귀 검증: 360×740, 글꼴 1.3배에서 목록 끝·선택 도구·하단 메뉴가 겹치지 않음, 모달이 선택 도구보다 위에서 입력을 받음, 수입 그룹까지 스크롤 가능.
- 배포 버전: 1.0.0-rc.16+65. Windows Setup/Update/SHA256SUMS 및 Android AAB를 GitHub에 게시하고 Google Play 내부 테스트 트랙에 배포한다.

검증 완료: 전체 598개 테스트 통과, lib/test 정적 분석 통과, git diff --check 통과.
