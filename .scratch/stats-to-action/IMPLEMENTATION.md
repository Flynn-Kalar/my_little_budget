# 핵심 요약 및 통계 정리 연결 구현 결과

Status: ready-for-human

## 좁은 PC의 핵심 요약
- 오른쪽 패널을 배치할 공간이 부족하면 월간 요약 아래에 접이식 핵심 요약을 표시한다.
- 기본 상태에서 월말 예상 순수입, 남은 예정 지출, 예정 거래 건수를 표시한다.
- 펼치면 오늘 지출 및 가까운 예정 거래 최대 3건을 확인한다.
- 데스크톱 상단 정보 영역을 독립적으로 스크롤하고 거래 목록 공간을 남긴다. 기존 shell 및 사이드바를 유지하며 모바일 거래 화면은 변경하지 않았다.
- 넓은 패널과 접이식 요약은 동일한 계산을 사용한다. 월말 예상은 해당 월에 등록한 수입·지출을 한 번씩 반영한다. 기존 패널의 미래 거래 이중 계산과 이체 차감 문제를 수정했다.
- 로딩/실패 시 0원으로 오인하지 않도록 별도 메시지와 재시도를 표시한다.

## 통계에서 정리로 이동
- PC/모바일 월간 통계에 해당 월 지출 내역 정리 및 예산 조정 버튼을 추가했다.
- PC 카테고리 상세 및 태그 상세, 모바일 카테고리·태그 시트에서 해당 범위의 내역 정리 버튼을 제공한다.
- 내역으로 이동할 때 월·지출 유형·카테고리·태그 또는 태그 없음 조건을 전달한다. 날짜 범위를 명시해 다른 달이 섞이지 않으며, 이전 검색/금액/계좌 조건은 교체한다.
- 이동한 내역에서 기존 개별 편집 및 앞서 추가한 일괄 수정으로 분류를 변경할 수 있다.
- 예산 조정 버튼은 통계에서 선택한 월의 예산 화면을 연다. 특정 그룹을 임의로 선택하거나 자동 수정하지 않는다.
- 모바일은 중첩된 통계 시트를 모두 닫고 내역 또는 예산 화면을 연다.
- 연간 통계 화면은 이번 변경 대상이 아니다.

## 검증
- 정적 분석: 문제 없음.
- 전체 Flutter 테스트: 435개 통과.
- 신규 테스트 8개: 예상 계산 및 정렬 2개, PC 500px/760px 높이에서 펼침·필터·800/1600/500px 전환 및 입력 보존, PC 카테고리/태그/태그 없음 필터 전달 3개, 과거 월 예산 이동, Android 중첩 시트 닫기 및 필터 전달.
- 기존 PC 500/600px Windows/Linux/macOS UI와 Android/iOS UI, 거래 자동완성 및 통계 태그 상세 회귀 테스트 통과.
- 마지막 스크롤 설정 변경 후 좁은 PC 레이아웃 테스트 추가 재검증 통과.

후속 요청으로 Windows 설치본과 서명된 Android AAB 빌드를 완료했다. 상세 결과는 `BUILD.md` 참고. 배포는 수행하지 않았다.
