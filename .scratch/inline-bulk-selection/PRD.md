# 목록 안에서 길게 눌러 다중 선택

Status: complete (local source)

## 요청

다중 선택을 별도 목록 대화상자로 열지 않는다. 실제 목록 항목을 길게 누르면 체크박스가 나타나고 해당 항목이 바로 선택되어야 한다.

## 적용

- PC·모바일의 카테고리, 태그, 자산, 메모, 일정/D-day, 반복 거래, 프리셋, 예산 그룹, 투자 거래 목록에 적용한다. 거래내역의 기존 길게 누르기 선택 방식은 유지한다.
- 선택 모드에서 행을 누르면 선택/해제하고 기존 편집·상세·스위치·메뉴 등의 항목 내부 동작은 실행하지 않는다.
- 작업 막대는 같은 화면 하단에 고정한다. 스크롤 시에도 선택 개수·전체 선택·선택 취소·항목별 일괄 작업을 사용할 수 있다. 목록 아래 여백을 확보한다.
- 선택 화면을 위한 Navigator route, Dialog, bottom sheet를 만들지 않는다. 삭제 최종 확인과 태그 카테고리 지정 입력은 기존 작업 대화상자를 유지한다.
- 성공 시 화면을 닫지 않고 선택 모드를 종료해 기존 목록을 갱신한다. 실패 시 선택을 유지한다.
- 모바일 뒤로가기는 선택 취소를 우선한다. 선택이 없으면 기존 홈 복귀/종료 규칙을 따른다.
- 캘린더 전체 선택은 현재 월의 보이는 날짜 범위에 속한 일정만 선택하고 D-day에서는 D-day 목록만 선택한다.
- 공통 선택 상태와 행/작업 막대만 공유하고 PC·모바일 전용 화면을 각각 연결한다.
- 이번 요청은 수정이며 GitHub 푸시·새 설치본 배포·AAB 생성은 포함하지 않는다.

## 검증

- PC·모바일 9개 영역에서 실제 행 길게 누르기 → 체크 표시 → 행 선택/해제 → 취소를 확인한다.
- 카테고리 삭제 확인 취소/완료, 태그 카테고리 지정, 자산 보관, 월간 일정·D-day 선택, 모바일 투자 마지막 항목 삭제 후 연간 결과 갱신을 확인한다.
- 좁은 화면에서 작업 막대 고정, 사용 중 카테고리 삭제 실패 시 원자성, 모바일 뒤로가기 선택 취소를 확인한다.

## 결과

- 다중 선택 전용 창을 제거하고 기존 목록의 행과 체크박스를 연결했다. 삭제 확인과 카테고리 입력 대화상자만 유지한다.
- 전체 테스트 547개 통과. 마지막 캘린더 범위 보완 이후 관련 UI 31개 재검증 통과. 정적 분석 문제 없음.
- 실제 PC·모바일 9개 영역의 길게 누르기, 월간·D-day, 카테고리 삭제, 태그 지정, 자산 보관, 투자 연간 결과 갱신, 스크롤·뒤로가기를 검증했다.
- GitHub 푸시·AAB 생성·Windows 설치본 배포는 수행하지 않았다.
