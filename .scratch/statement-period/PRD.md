# 내역 월별 집계 시작일

Status: complete (local source)

- 모바일·PC 설정에서 시작일 1~31일 또는 월 마지막 날 선택. 기본 1일.
- 주말과 앱의 대한민국 공휴일 데이터에 따라 그대로/이전/다음 영업일 선택.
- 없는 일자는 해당 월 말일로 보정. 해당 월 시작일 포함, 다음 월 시작일 제외로 기간을 계산하여 누락·중복을 막는다.
- 내역 목록, 합계, 카테고리 요약, 내역의 월별 추세에 동일 기간 적용. 검색의 전체 기간 및 직접 지정 날짜 필터는 기존 의미 유지.
- PC·모바일 내역 상단에 실제 기간 표시. 설정은 기기 SharedPreferences에 저장. 예산·통계의 별도 페이지는 기존 달력 월 기준 유지.
- 기존 공휴일 데이터 밖의 새 임시공휴일은 공휴일 데이터 업데이트가 필요하다.

## 검증
- 0~31일 × 휴일 처리 3가지 × 24개월의 경계 연속성, 윤년, 월말, 연말, 공휴일 이동 테스트 통과.
- 실제 DB와 provider로 기간 경계 거래 포함/제외, 합계·카테고리·추세 일치 및 설정 변경 반영 검증.
- 설정 저장 후 새 provider에서 복원 확인.
- 전체 테스트 중 583개 통과, 모바일 설정 업데이트 버튼 테스트 1개는 새 설정 카드로 목록이 길어져 스크롤 필요. 실제 스크롤 후 누르도록 수정하고 관련 테스트 8개 모두 통과.
- 정적 분석 지적 없음. 배포 전 소스 상태.
