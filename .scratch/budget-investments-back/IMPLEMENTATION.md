# 구현 및 검증

2026-10-19 코드 반영. 이번 작업에서는 빌드·설치·GitHub 배포를 수행하지 않았다.

- PC 예산·투자 제목 왼쪽에 chevron 뒤로가기 버튼을 추가했다. 제목 텍스트는 한 번만 표시하며 클릭 동작을 연결하지 않는다.
- 돌아갈 페이지가 없는 직접 진입/사이드바 진입에서는 버튼을 숨긴다. 라우터 없는 독립 위젯에서도 오류 없이 숨긴다.
- PC 내역의 예산/투자 이동을 `push`로 변경했다. 모바일의 기존 `push` 이동은 유지했다.
- 뒤로가기는 실제 라우트 스택을 `pop`해 내역 화면을 다시 만드는 대신 기존 화면으로 복귀한다.
- 사용자 정정에 따라 모바일에 추가했던 버튼과 leading 슬롯은 모두 제거했다. shell 분기 및 플랫폼 정책은 유지했다.
- 이전 일괄 삭제 작업은 그대로 유지했다.

검증:

- `flutter test --no-pub test/ui/budget_investments_back_test.dart`: 수정 후 8개 통과.
- Windows compact/wide에서 두 목적지의 제목이 한 번만 나타나고, 제목 텍스트 클릭은 이동하지 않으며 chevron 클릭만 복귀하는 것을 확인했다. 기존 내역 위젯, 월/유형/검색 조건, PC의 입력 금액과 목록 스크롤 위치가 유지된다.
- 모바일에서는 새 버튼이 없으며 기존 시스템 뒤로가기가 유지되는 것을 확인했다.
- 각 플랫폼의 직접 예산/투자 진입 시 비활성 뒤로가기 버튼을 노출하지 않는 것을 확인했다.
