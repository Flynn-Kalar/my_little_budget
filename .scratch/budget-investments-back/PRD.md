# 내역에서 예산·투자 방문 후 돌아가기

- 내역의 예산/투자 버튼으로 이동하면 해당 페이지 제목 왼쪽에 `<` 뒤로가기 버튼을 표시한다.
- PC에만 적용하며, 눌렀을 때 기존 내역 화면으로 돌아간다. 모바일은 기존 동작을 유지한다.
- 제목은 한 번만 표시하고 `<` 버튼만 클릭 가능하다. 제목 글자를 클릭해도 돌아가지 않는다.
- PC의 기존 `go` 이동을 `push`로 변경해 원래 내역의 입력/필터/스크롤 상태를 보존한다.
- 사이드바나 직접 주소 등으로 처음 연 페이지에서는 돌아갈 경로가 없으면 버튼을 숨긴다.
- shell/플랫폼 정책과 기존의 다른 페이지 이동 방식은 유지한다.
- 코드 개선 범위이며 빌드·설치·배포는 포함하지 않는다.
