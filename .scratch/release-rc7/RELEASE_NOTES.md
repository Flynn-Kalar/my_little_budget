# My Little Budget 1.0.0-rc.7 (build 56)

- PC 거래내역의 좌우 여백, 날짜·합계·카드 정렬, 긴 금액과 텍스트 처리를 개선했습니다.
- 통계 도넛 중앙 글자를 키우고 PC 최근 12개월 추세를 차트·요약·월별 표 구성으로 정리했습니다.
- PC·모바일 태그 편집에서 여러 카테고리를 지정할 수 있습니다. 거래 카테고리 지정 태그를 먼저 표시하고 각 그룹은 전체 사용 빈도순으로 정렬합니다.
- PC·모바일 카테고리 편집에서 검색 가능한 아이콘 57종 중 선택할 수 있습니다. 홈 최근 내역·거래내역에도 동일하게 적용합니다.
- 캘린더에서 빈 날짜를 누르면 선택 날짜의 일정 추가창을, 일정이 있는 날짜를 누르면 당일 전체 목록을 엽니다.
- 일정에 D-day를 지정하고 캘린더의 D-day 탭에서 전체 목록을 볼 수 있습니다. 시작 날짜 기준으로 D-n / D-day / D+n을 표시합니다.
- 기존 데이터 마이그레이션, 백업과 동기화에서 새 설정을 유지합니다.

검증: 전체 테스트 503개 통과, 정적 분석 문제 없음.

이번 요청 범위는 서명된 Android AAB 생성과 GitHub 소스 푸시입니다.
Windows 설치 파일 생성·설치, GitHub Release 게시, Play Console 업로드는 수행하지 않습니다.

Android 산출물: `MyLittleBudget-Android-1.0.0-rc.7.aab` (versionCode 56)
