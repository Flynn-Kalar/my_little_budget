# 메모 목표금액 계산식과 빈 여백 편집

Status: complete (local source)

- 모바일·PC 공통 목표금액 폼의 목표·현재·추가 금액에 사칙연산과 괄호를 지원한다. 기존 금액 계산기를 재사용하고 원 단위 반올림을 따른다.
- 오류를 0원으로 처리하지 않도록 nullable 계산 함수를 분리한다. 잘못된 식, 0 나눗셈, 금액 범위 초과는 저장을 막는다.
- 모바일에서도 연산자를 입력할 수 있는 키보드를 사용한다.
- PC 메모 조회 창의 별도 편집 안내와 72px 영역을 삭제하고 창 내부의 자연스러운 빈 여백에서 편집할 수 있도록 한다. 체크박스와 닫기 버튼은 독립 동작한다.
- 모바일의 기존 빈 여백 편집·스크롤 동작을 유지한다.
- 단순 수정 요청이며 빌드·배포·버전 변경은 하지 않는다.
