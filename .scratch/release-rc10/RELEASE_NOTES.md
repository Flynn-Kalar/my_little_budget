# 나만의 작은 가계부 1.0.0-rc.10 (59)

## 변경 사항

- PC와 모바일의 자산·예산·투자·메모·일정·설정 목록에서 항목을 길게 눌러 같은 화면에서 다중 선택할 수 있습니다. 하단 작업 막대에서 전체 선택·취소와 일괄 작업을 수행합니다.
- PC 투자 화면을 보유 종목·거래 내역·실현손익 탭으로 정리했습니다. 종목 검색과 계좌 필터, 종목별 상세 내역과 빠른 거래 입력을 제공합니다.
- PC 투자 보유 종목의 현재가를 수동 입력해 평가 금액과 평가손익을 확인할 수 있습니다. 현재가는 각 기기에 저장되며 거래 원가와 계좌 잔액은 변경하지 않습니다.
- 메모의 목표 금액과 현재 금액에 음수를 입력하고 모바일에서 추가 금액으로 차감할 수 있습니다. PC에서는 현재 금액을 직접 수정하도록 정리했습니다.
- PC 거래 내역을 아래로 스크롤하면 요약 카드가 접히고 위로 스크롤하면 다시 표시됩니다.

## 파일 안내

- Windows Setup.exe와 Update.exe는 같은 전체 설치 패키지이며 기존 설치와 데이터를 유지하며 업그레이드합니다.
- Android AAB는 Google Play 업로드용 서명 번들이며 versionCode는 59입니다. GitHub 게시와 Google Play 배포는 별개입니다.
- SHA256SUMS.txt로 Windows 설치 파일 두 개와 Android AAB를 검증할 수 있습니다.
- rc.9 이전 버전에서 메모 동기화를 사용하는 경우 rc.9 릴리스의 Supabase 서버 SQL 적용 안내도 확인하세요.

검증: 전체 테스트 558개 통과, 정적 분석 문제 없음.
