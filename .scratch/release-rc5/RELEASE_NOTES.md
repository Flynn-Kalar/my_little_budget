# My Little Budget 1.0.0-rc.5 (build 55)

- PC 예산 화면에서 총 예산·총 사용액·남은 금액을 왼쪽에 세로로, 하루 사용 가능 예산을 오른쪽에 배치했습니다.
- 넓은 PC 화면에서 두 영역의 높이를 맞추고 좁은 PC 영역에서는 위아래로 배치합니다.
- PC의 하루 사용 가능 예산 기준 일수는 제목 아래 한 번만 표시합니다.
- 예상 소득 카드는 상단 전체 폭을, 예산 그룹 카드는 아래쪽 배치를 유지합니다.
- 모바일의 기존 배치와 그룹별 기준 일수 표시, 예산 계산식은 유지합니다.

사용자 요청에 따라 Android 버전 코드는 **55**를 유지했습니다.

- Android: `MyLittleBudget-Android-1.0.0-rc.5.aab`
- Windows 신규 설치: `MyLittleBudget-Setup-1.0.0-rc.5.exe`
- Windows 앱 내 업데이트: `MyLittleBudget-Update-1.0.0-rc.5.exe`
- 파일 검증값: `SHA256SUMS.txt`

이번 배포는 GitHub 게시이며 Play Console 업로드나 로컬 PC 설치는 수행하지 않습니다.
