# 나만의 작은 가계부 1.0.0-rc.8 (57)

- 카테고리·태그·자산·메모·일정·반복 거래·프리셋·예산·투자 내역에 다중 선택과 항목별 일괄 작업을 추가했습니다.
- 태그 여러 개의 카테고리를 한 번에 추가·교체·해제할 수 있습니다. 자산은 여러 개를 선택해 보관할 수 있습니다.
- PC와 모바일에서 반복 거래의 표시 순서를 드래그 또는 위·아래 버튼으로 변경하고 저장할 수 있습니다.
- 모바일 자산 거래내역 제목과 PC·모바일 공통 월 구분 헤더를 추가했습니다.
- 거래 요약의 표현을 '월말 예상 순수입'으로 명확히 했습니다. 해당 월에 등록된 예정 거래를 포함한 수입에서 지출을 뺀 값이며 이체는 제외합니다.

이전 Windows 공개 버전 이후 반영된 변경도 포함합니다.

- 태그에 카테고리를 지정하고, 선택한 카테고리와 사용 빈도에 따라 태그를 우선 표시합니다.
- 다양한 카테고리 아이콘 선택과 거래 목록·홈의 아이콘 표시를 지원합니다.
- 캘린더에서 빈 날짜를 누르면 일정 추가, 일정이 있는 날짜를 누르면 일정 목록을 표시합니다. D-day 설정과 모아보기 목록을 제공합니다.
- 거래 목록 여백·정렬, 통계 글자 크기와 PC 12개월 추세 디자인을 개선했습니다.

## 배포 파일

- Setup.exe: Windows 신규 설치용
- Update.exe: Windows 앱 내 업데이트용 (Setup과 동일한 전체 설치 패키지)
- Android.aab: Google Play 업로드용 서명된 Android 번들 (versionCode 57)
- SHA256SUMS.txt: 배포 파일 검증값

기존 AppId와 데이터 저장 위치를 유지합니다. Google Play 게시 작업은 포함하지 않습니다.
