# 메모 통합과 목록 안에서 순서 편집

Status: complete (local source)

## 요청과 동작

- 메모 유형 선택을 없애고 새 금액 목표는 본문 도구 모음으로 삽입한다.
- 기존 메모 수준의 목표는 편집 초안에서 본문 블록으로 가져온다. 저장할 때 기존 목표 필드를 비우고 본문을 함께 저장한다. 취소하면 원본은 그대로 유지한다. 이전 임시 초안의 목표도 복구 시 본문에 넣는다.
- PC와 모바일 메모에 순서 편집을 제공한다. 고정 메모와 일반 메모의 각 그룹 안에서만 이동한다. 검색 결과가 아닌 전체 메모 그룹을 편집한다.
- 반복 거래의 별도 순서 편집 대화상자를 없애고 카테고리처럼 현재 페이지에 위·아래 버튼과 취소·순서 저장을 표시한다.
- 모바일 자산·태그·카테고리의 즉시 이동 메뉴도 같은 미리보기·저장 방식으로 바꾼다. PC의 기존 자산·태그·카테고리 순서 편집 방식은 유지한다.
- 순서 편집 진입 시 다중 선택을 해제한다. 저장 실패 시 편집 순서를 유지하고 오류를 표시한다. 뒤로가기는 순서 편집 취소를 우선한다.

## 데이터

- 로컬 DB v26에 notes.sort_order를 추가한다. 기존 메모는 0으로 유지하여 기존 정렬을 보존하고, 저장한 그룹 순서는 이후 메모 수정에도 유지한다.
- 그룹 전체 ID를 검증하고 트랜잭션으로 저장한다. 그룹 변경·누락·중복·중간 쓰기 실패 시 부분 저장하지 않는다.
- 백업과 JSON 기반 메모 동기화에 순서를 포함한다. 이전 백업은 0을 사용하고 이전 클라이언트의 순서 없는 동기화 데이터는 현재 기기의 순서를 보존한다.
- 서버 테이블 변경이나 알람 설정 변경은 필요하지 않다.
