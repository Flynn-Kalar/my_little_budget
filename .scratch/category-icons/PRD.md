# 카테고리 아이콘

Status: ready-for-human

## 구현

- PC·모바일 설정 > 카테고리 관리 > 추가/수정에 검색 가능한 아이콘 선택창 제공.
- 식사, 카페, 교통, 주거, 의료, 반려동물, 취미, 급여 등 57종의 Material 아이콘 사용.
- 선택하지 않은 기존 카테고리는 이름과 수입/지출 유형으로 자동 표시. 알 수 없는 이전 아이콘 값도 자동 표시로 대체.
- 기존 categories.icon 필드에 안정적인 문자열 키 저장. 스키마 변경 없음.
- 명시적인 사용자 선택을 자동 추천보다 우선하고 자동 선택으로 되돌릴 수 있음.
- 공통 배지는 홈 최근 내역, PC·모바일 거래내역, PC 자산별 거래내역과 카테고리 관리에 적용.
- 저장된 카테고리 색상의 연한 배경과 식별 가능한 도형을 함께 표시.
- 모바일 카테고리 수정 시 기존 색상을 보존하도록 보완.
- 카테고리 수정 후 거래·자산별 거래·통계 상세 조회 캐시 갱신.

## 검증

- PC·모바일 검색·선택·저장·재편집·자동 선택 복원.
- 거래별/월별/자산별/최근 입력 조회, 백업 및 기기 간 동기화에서 선택 유지.
- 전체 테스트 496개 통과. 정적 분석 문제 없음.

## 배포

로컬 소스에 반영. 앱 설치 업데이트, GitHub 게시와 AAB 생성은 요청 범위에 포함하지 않음.
