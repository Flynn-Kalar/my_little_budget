# PC 투자 페이지 시안 구현

Status: complete (local)

사용자 요청: 대화에서 생성한 민트 투자 페이지 시안에 최대한 가까운 실제 UI 구현. 기존 기능 유지. 모바일 UI 변경 없음. 배포 요청 없음.

## 구현

- PC 본문 최대 폭 1440, 상단 제목·기간·오늘·거래 추가, 원형 아이콘의 매수/매도/배당/실현손익 카드 4개.
- 흰색 메인 카드에 보유 종목 / 거래 내역 / 실현손익 탭, 검색·계좌 필터와 펼침 상세 필터.
- 보유 종목 표: 종목별 문자 아이콘, 계좌, 수량, 평균 매수가, 현재가, 평가 금액, 평가손익·수익률.
- 행 펼침: 매입/평가/선택 기간 배당금, 현재가 수정·추가 매수·매도·배당금 추가. 매도/배당 버튼으로 기존 검증 및 저장 폼을 연다.
- 시안의 현재가 기능을 수동 입력으로 구현. SharedPreferences에 기기별 저장, 현재가 지우기 지원. 미입력 값은 —로 표시한다. 평가손익은 입력한 종목만 계산하며 매입 원가·거래·계좌 잔액은 바꾸지 않는다. 거래 동기화/백업 형식 변경 없음.
- 월/연 조회, 매수/매도/배당·기간·종목·계좌 필터, 거래 수정/삭제/다중선택 유지. 실현손익에도 현재 검색·거래 필터를 적용한다.
- 좁은 네이티브 PC에서는 desktop shell을 유지하며 헤더·표 등 밀집 영역만 가로 스크롤한다. 긴 금액에 말줄임을 사용하지 않는다.

## 검증

- 전체 558개 테스트 통과. 마지막 시각 조정 후 관련 61개 테스트 재검증 통과. flutter analyze 문제 없음.
- 폭 650/1440 포트폴리오·탭·검색, 현재가 입력·잘못된 값 거부·평가손익 계산·원가 불변, 기기 저장 및 삭제 검증.
- 기존 투자 CRUD/연간 조회/뒤로가기/다중선택 회귀 검증.
- 테스트 데이터로 실제 화면 렌더링을 생성해 정렬을 확인. desktop-preview.png 참고. capture_test.dart는 로컬 시각 검증용으로 Windows 글꼴을 읽는다.
