# My Little Budget 1.0.0-rc.6 (build 55)

## 변경 사항

- 민트색 배경과 흰색 카드로 공통 테마를 정리했습니다.
- 실제 예산·수입·지출·최근 내역을 보여주는 홈 화면을 추가했습니다.
- PC 사이드바에 홈 메뉴를 추가했습니다.
- 거래내역의 요약 카드와 월간·연간 통계 화면을 개선했습니다. 기존 검색·필터·거래 편집 및 통계 상세 조회 기능은 유지합니다.
- 자산·투자·예산·메모·캘린더·설정에도 공통 테마를 적용했습니다. 해당 화면의 개별 정보 구성은 유지합니다.
- 모바일용 홈 버튼은 추가하지 않았습니다. 앱 실행 시 홈으로 진입하고, 각 기본 탭에서 뒤로가기를 누르면 홈으로 돌아오며 홈에서 뒤로가기를 한 번 누르면 종료하도록 처리했습니다.
- 넓은 모바일 화면에서도 홈 버튼 없이 동일한 뒤로가기 정책을 적용하고, 셸과 페이지가 같은 화면 폭 기준을 사용하도록 개선했습니다.

## Windows 다운로드

- 신규 설치: `MyLittleBudget-Setup-1.0.0-rc.6.exe`
- 기존 앱 업데이트: `MyLittleBudget-Update-1.0.0-rc.6.exe`
- 파일 검증값: `SHA256SUMS.txt`

두 EXE는 동일한 전체 설치 패키지이며 기존 AppId로 데이터를 유지하며 업그레이드합니다.

코드 검사와 전체 테스트 485개가 통과했습니다.

이번 배포는 Windows 전용입니다. Android AAB는 빌드·게시하지 않으며 Android 버전 코드는 55를 유지합니다.
