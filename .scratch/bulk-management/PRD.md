# 관리 화면 다중 선택과 일괄 처리

Status: ready-for-human

## 범위

PC·모바일의 각 원본 데이터 관리 화면에 `다중 선택` 버튼을 제공한다. 공통 선택창에서 항목을 검색하고 개별/검색 결과 전체 선택 후 처리한다. 기존 거래 내역의 다중 선택은 유지한다.

| 목록 | 일괄 동작 |
| --- | --- |
| 카테고리 | 삭제 |
| 태그 | 카테고리 추가/교체/해제, 삭제 |
| 활성 자산 | 보관 |
| 메모 | 상단 고정/고정 해제, 삭제 |
| 반복 거래 | 활성화/비활성화, 삭제 |
| 내역 프리셋 | 삭제 |
| 예산 그룹 | 삭제 |
| 투자 거래 내역 | 삭제 |
| 캘린더 원본 일정 및 D-day 목록 | 삭제 |

## 선택 범위와 확인

- 메모·투자는 현재 검색/필터 결과, 예산은 현재 월의 그룹이 대상이다.
- 카테고리는 수입·지출·보관 항목 전체, 태그는 전체, 자산은 활성 자산이 대상이다.
- 캘린더는 모든 원본 일정, D-day 모드에서는 D-day로 지정된 원본 일정이 대상이다. 반복 시리즈를 삭제한다는 사실을 확인창에 명시한다.
- 검색 중 전체 선택은 검색 결과에만 적용한다. 검색으로 가려진 기존 선택은 유지하고 총 선택 수와 확인창의 대상 이름으로 확인한다.
- 각 처리 전 건수·대상 이름·영향을 확인하며 취소/닫기는 데이터를 변경하지 않는다.
- 태그 카테고리는 기본적으로 추가 모드다. 교체 모드에서 빈 목록을 적용하면 전체 지정을 해제한다. 선택한 카테고리만 제거하는 해제 모드에서는 보관 카테고리도 선택 가능하다.

## 데이터 보존과 실패

- 모든 선택을 DB 안에서 재검증하고 한 트랜잭션으로 적용한다. 누락된 ID, 사용 중인 카테고리 또는 도중 실패 시 전체 원복하고 선택은 유지한다.
- 카테고리 삭제 제한 및 태그 지정 정리는 기존 DAO 규칙을 재사용한다.
- 태그 삭제는 거래·프리셋의 태그 연결을 정리하며 거래 자체는 보존한다.
- 자산은 보관만 제공하며 기존 거래는 보존한다.
- 예산 삭제는 예산 그룹, 반복 거래 삭제는 규칙만 삭제하며 기존 거래는 보존한다.
- 원본의 개별 수정/삭제 DAO와 동기화 변경 추적을 재사용한다. 스키마 변경은 없다.
- 성공 후 관련 목록·잔액·통계·알림을 갱신한다. 모바일 투자에서는 월간/연간 캐시도 함께 갱신한다.

## 검증

전체 테스트 517개 통과, 정적 분석 문제 없음. 카테고리 삭제 중 실패 시 태그 정리까지 원복, 태그 연결 및 메타데이터 보존, 오래된 선택 검증, 9종 데이터 작업, PC·모바일 주요 화면, 검색 선택 범위, 취소, 작은 화면/키보드, 마지막 투자 항목 삭제 후 연간 목록 갱신을 확인했다.
